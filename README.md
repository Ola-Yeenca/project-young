# House of Young

Entertainment platform for House of Young: events, talent management, gallery,
merch and enquiries, for Valencia and Lagos first.

- `backend/`: Django 5.2 backend, admin and API. Start with `backend/README.md`.
- `prototype/`: clickable website prototype (open `prototype/index.html`).
- `docs/DEPLOY.md`: Railway, Cloudflare and Resend setup.
- `docs/FRONTEND_BUILD_PROMPT.md`: prompt for building the real site from the prototype.
- `docs/GO_LIVE_PLAN.md`: scope, phases, costs and open decisions.
- `House Of Young/`: the original Django scaffold, kept for reference only. It is
  not used by the new backend and can be deleted.
